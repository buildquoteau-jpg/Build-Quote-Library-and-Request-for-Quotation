# BQ DeckMax Composite Decking
Category: Decking / Composite timber-look deck board
Product code: BQ-DECKMAX-COMPOSITE
Manufacturer: BQ Compform

BQ DeckMax is a co-extruded composite deck board system with a hardwearing polymer cap layer and timber fibre core. Suitable for residential and light commercial outdoor decking applications. Available in standard and wide board profiles across a range of timber-look colours.

## Specifications
- Australian made: yes
- BAL rating: 29
- Moisture resistant: yes

## Profiles
- 138mm Standard Board — BQ-DECKMAX-STD-138, 5,400 x 138 x 25mm, 5400×138×-×25mm, lm
- 190mm Wide Board — BQ-DECKMAX-WIDE-190, 5,400 x 190 x 25mm, 5400×190×-×25mm, lm
- 138mm Grooved Board — BQ-DECKMAX-GRV-138, 5,400 x 138 x 25mm (grooved), 5400×138×-×25mm, lm
