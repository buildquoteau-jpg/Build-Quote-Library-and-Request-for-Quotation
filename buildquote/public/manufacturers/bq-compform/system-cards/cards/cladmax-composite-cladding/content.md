# BQ CladMax Composite Cladding
Category: Cladding / Composite timber-look facade cladding
Product code: BQ-CLADMAX-COMPOSITE
Manufacturer: BQ Compform

BQ CladMax is a co-extruded composite facade cladding system with a UV-stable polymer cap layer and timber fibre core. Designed for residential and light commercial exterior wall applications. Tongue-and-groove profile for concealed fixing. Available in Shadowline and Vertical Batten profiles across a range of timber-look and solid colours.

## Specifications
- Australian made: yes
- BAL rating: 12.5
- Moisture resistant: yes

## Profiles
- 150mm Shadowline — BQ-CLADMAX-SL-150, 5,400 x 150 x 20mm, 5400×150×-×20mm, lm
- 300mm Shadowline — BQ-CLADMAX-SL-300, 5,400 x 300 x 20mm, 5400×300×-×20mm, lm
- 90mm Vertical Batten — BQ-CLADMAX-VB-90, 5,400 x 90 x 32mm, 5400×90×-×32mm, lm
