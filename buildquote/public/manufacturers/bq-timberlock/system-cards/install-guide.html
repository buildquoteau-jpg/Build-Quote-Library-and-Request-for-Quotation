Installing your System Card website package

This folder is a complete, self-contained mini-website with 2 System Cards for BQ TimberLock. It has no server code and no database — it is plain HTML, JavaScript and images, so it can be hosted anywhere.

1. Upload the folder

Upload the entire system-cards folder to your website so it is reachable at:

https://buildquote.com.au/manufacturers/bq-timberlock/system-cards/

How you upload depends on your hosting: your web developer, cPanel / hosting file manager, FTP/SFTP, or your CMS's static file area. The folder must keep its internal structure (assets/, cards/).

2. Check it works

Open https://buildquote.com.au/manufacturers/bq-timberlock/system-cards/ in a browser. You should see your branded collection page; every tile opens a full System Card with selectable line items, a shopping list and PNG sharing — all running in the visitor's browser.

3. Link it from your site

  • Add a menu item (e.g. System Cards) pointing at /system-cards/.
  • card-link-list.csv has the direct URL for every card — use them in quotes, emails and spec documents.
  • Each card folder contains a print-ready qr-code.png pointing at that card's page.
  • embed-snippets.html has copy-paste iframe/button snippets for pages that should surface a single card.

Updating

When your cards change, generate a new package in BuildQuote Data Studio and replace the whole system-cards folder. Never edit files inside the folder by hand — changes are lost on the next update.

Using Wix or a builder that can't host uploaded folders? Use the Embeds & Links options in BuildQuote Data Studio instead.
